# Forma Furniture Showroom

A Vite + React furniture showroom demo with a warm, colorful light-only theme.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Source structure

- `src/customer/` — Home, Collection, Product, Cart, Checkout, Contact, Wishlist
- `src/admin/` — Admin login and dashboard
- `src/components/` — Navbar, Footer, ProductCard
- `src/context/` — Store state and localStorage persistence
- `src/data.js` — Demo product data
- `src/style.css` — Light-only visual theme

## Theme

The UI uses Forest Green, Terracotta, Burnt Clay, Warm Gold, Sage, Sand and Cream. There is no dark-mode implementation.
